About Unified Social Media Threat Detector

Project Overview

The Unified Social Media Threat Detector is an AI-powered system designed to detect fake profiles, spam accounts, scams, and automated bots across social media platforms (Twitter/X, Instagram, Facebook). It combines multi-modal analysis of content, activity patterns, network relationships, and profile images into a unified detection framework with explainable risk scoring.

This project was developed for the Smart India Hackathon (SIH) 2026 under the theme "Cybersecurity / Digital Trust and Safety" as part of the Adaptive Social Engineering Defense Framework (ASEDF).

Technical Approach
Analysis Modules
  • Content Analyzer: Suspicious keywords, spam patterns, sentiment analysis, content diversity
  • Activity Analyzer: Posting frequency, engagement rates, temporal patterns, regularity
  • Network Analyzer: Follower/following ratios, mutual connections, reciprocity, isolation
  • Image Analyzer: Default images, stock photos, AI-generated face detection
Machine Learning
  • Models Compared: Random Forest, Gradient Boosting, Logistic Regression, Neural Network, SVM, Naive Bayes, KNN, Decision Tree
  • Features: 30+ behavioral, content, network, and image features
  • Training: Cross-validation, hyperparameter tuning, synthetic + real data
  • Explainability: Feature importance, indicator-based reasoning, actionable recommendations
Key Features
  • Multi-platform support (Twitter/X, Instagram, Facebook)
  • Real-time single profile analysis
  • Batch processing via CSV/JSON upload
  • RESTful API for integration
  • Explainable risk scores with indicators
  • Threat classification (fake, spam, scam, bot)
  • Model training and retraining interface
  • Model performance monitoring
  • Responsive web interface
  • Comprehensive logging and audit trail
